# 개구리 중사 케로로 — 소대 출동!

케로로 포스터에서 시작한 한 화면의 반응형 인터랙티브 웹페이지. 왼쪽 아래 모니터에서 다섯 소대원이 차례로 등장하고 마지막에 한국어 타이틀이 완성됩니다. 캐릭터를 크게, 타이틀은 작게 배치하고 소개 섹션 없이 연출과 상호작용에 집중했습니다.

## 실행

Node.js 20 이상에서 별도 패키지 설치 없이 실행됩니다.

```sh
npm run dev
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 다른 포트는 `npm run dev -- --port 5173`으로 지정할 수 있습니다.

```sh
npm test         # 등장 순서와 좌표 계산 검증
npm run build   # 정적 배포용 dist/ 생성
npm run preview # dist/ 미리보기
```

`dist/`를 정적 웹 호스팅에 업로드할 수 있습니다. 모든 에셋 경로가 상대 경로라 하위 경로에서도 동작합니다. 글꼴은 Google Fonts를 사용하며, 연결되지 않으면 기기의 기본 한국어 글꼴로 표시합니다.

## 인터랙션

- 이미지 준비 후 약 6초의 등장 시퀀스 자동 재생
- 기로로 → 타마마 → 쿠루루 → 도로로 → 케로로 → 한국어 타이틀
- 모니터 점등 → 화면 앞으로 돌진하는 원근 확대 → 반동과 함께 안착
- 등장 순간 카메라 흔들림, 방사형 속도선, 발사 궤적, 색종이·별·원형 충격파, 피날레 집중선
- 다시 출동, 일시정지/계속, 건너뛰기, 모니터 클릭으로 재생
- 캐릭터를 누르면 각자 다른 움직임과 색상의 파티클로 반응
- 마우스 이동에 따른 원근 움직임, 빈 배경을 누르면 파티클 발생
- 효과음은 기본 꺼짐. 사용자가 켰을 때만 Web Audio로 합성
- OS의 동작 줄이기 설정을 존중하여 완성 화면부터 표시
- 375px 모바일부터 데스크톱까지 캐릭터가 서로 겹치고 화면 가장자리까지 채우는 포스터 배치

## 구조

| 파일 | 역할 |
| --- | --- |
| `index.html` | 한 화면의 포스터와 재생 제어 |
| `styles.css` | 반응형 포스터 배치, 모니터, 장식 |
| `src/scene.js` | 소대 데이터, 시퀀스 타이밍, 좌표 계산 |
| `src/animation.js` | Web Animations API 기반 단일 재생 시간축 |
| `src/particles.js` | Canvas 파티클, 최대 개수와 해상도 제한 |
| `src/audio.js` | 사용자 동작으로 활성화되는 효과음 |
| `src/main.js` | UI 연결, 이미지 준비, 포인터 상호작용 |
| `assets/` | 투명 캐릭터 PNG 5개, 한국어 로고, 이전 일본어 로고, 파비콘 |
| `scripts/` | 의존성 없는 로컬 서버와 정적 빌드 |

원본 포스터의 자세를 기준으로, 가려진 부분을 복원한 이미지 에셋입니다. 제작 방식과 프롬프트 방향은 `docs/assets.md`에 기록했습니다.

## 브라우저 검증

Playwright와 Chrome이 있는 환경에서:

```sh
node tests/browser.mjs
```

Playwright 모듈이 별도 경로에 있는 경우 `PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs`를 지정합니다. 기본 브라우저 채널은 `chrome`이며 `PLAYWRIGHT_CHANNEL`로 바꿀 수 있습니다. 스크린샷은 `/tmp/keroro-qa`에 저장됩니다.

데스크톱 및 모바일, 재생과 일시정지, 연속 재시작, 캐릭터 반응, 마우스 움직임, 효과음 전환, 동작 줄이기, 이미지 실패를 검증합니다.
