# 개구리 중사 케로로 — 인터랙티브 포스터

2026-10-14. 사용자 제공 포스터를 기반으로 하는 반응형 애니메이션 웹페이지.

## 현재 요청과 방향

한국어 버전으로 변경하고 하단 캐릭터 소개, 모달, 내비게이션, 배너와 푸터를 제거한다. 한 화면에 큰 캐릭터 다섯 명과 작은 중앙 타이틀을 배치한다. 원본 포스터의 자세를 기준으로 가려진 부분을 복원한 기존 캐릭터 에셋은 유지한다.

왼쪽 아래 모니터 점등 → 다섯 캐릭터의 순차 발사 → 마지막 한국어 타이틀 등장으로 약 6초의 시퀀스를 구성한다. 모니터 주변 충격파, 별과 색종이, 발사 궤적, 탄성 이동, 피날레 집중선을 사용한다. 완성 후에는 캐릭터마다 다른 클릭 반응과 파티클, 마우스를 따라 움직이는 원근 효과, 배경 클릭 파티클을 제공한다.

크림색 배경, 초록과 노랑, 굵은 윤곽선, 종이 질감과 점무늬를 사용한다. 데스크톱은 펼쳐진 포스터, 모바일은 세로 포스터다. 소개나 행사 안내 대신 작은 재생 제어만 남긴다.

추가 확대 요청에 따라 캐릭터를 약 30~45% 더 키웠으며, 화면 가장자리에서 실루엣 일부가 잘리고 서로 겹치도록 배치했다. 케로로는 최종 배치에서 다른 소대원 뒤에 놓여 겹친 영역에서도 다른 캐릭터를 누를 수 있다. 타이틀은 작은 크기를 유지하고 조금 위로 올려 도로로의 눈을 가리지 않는다.

등장 중에는 캐릭터를 최상단으로 올린다. 모니터에서 작게 출발해 화면 중앙을 향하고, 원근 투영과 확대를 합쳐 최종 크기의 약 1.9배로 전진한 뒤 반동과 함께 안착한다. 각 돌진에 짧은 화면 흔들림과 방사형 속도선을 동기화한다. 흔들림은 기존 재생 시간축에 포함되어 정지·건너뛰기·재시작·화면 크기 변경을 함께 따른다. 동작 줄이기 설정에서는 생략한다.

## 구현

2026-10-26 사용자 요청에 따라 HTML/CSS/jQuery 구조로 단순화했다. jQuery 3.7.1은 로컬 배포본을 포함한다. `main.js`에서 이벤트, 클래스와 CSS 변수를 제어하고 `animations.css`에서 등장, 클릭 반응, 파티클을 재생한다. 이전 ES 모듈, 클래스 기반 재생기, Canvas와 Web Animations API 구현은 제거했다. 효과음은 로컬 WAV 파일을 HTML 오디오로 재생한다.

`is-playing`, `is-complete`, `is-paused` 클래스로 상태를 표현한다. CSS 지연값으로 등장 순서를 정하고 진행 막대의 `animationend` 이벤트로 완료를 처리한다. 일시정지는 `animation-play-state`를 사용하며 별도의 프레임 타이머를 두지 않는다. 파티클은 수명이 끝나면 제거되는 HTML 요소이고, 최대 6묶음으로 제한한다. 기능과 코드 예시는 `docs/features.md`에서 설명한다.

투명 PNG 캐릭터 5종과 한국어 로고는 `assets/`에 저장한다. 모니터, 장식과 단순 아이콘은 CSS/SVG다. 캐릭터의 크기와 배치는 이번 구현 변경에서 유지한다.

## 재생과 접근성

이미지 준비 후 자동 재생하며 다시 출동, 일시정지/계속, 건너뛰기, 모니터 클릭으로 제어한다. 효과음은 사용자가 켠 뒤에만 재생한다. 동작 줄이기 설정에서는 정지된 완성 화면부터 표시하고 클릭 모션과 패럴랙스도 생략한다. 버튼은 키보드로 조작할 수 있으며 포커스 표시와 대체 텍스트를 제공한다.

재시작 시 이전 애니메이션과 반응을 취소한다. 일시정지 시 등장, 부유, 클릭 반응, 파티클과 패럴랙스를 멈춘다. 화면 크기가 바뀌면 모니터 시작점을 다시 계산한다.
