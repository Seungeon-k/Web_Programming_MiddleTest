# ケロロ小隊、出動！

2026-10-14. 사용자 제공 케로로 포스터를 기반으로 제작하는 반응형 애니메이션 웹페이지.

## 요청과 방향

왼쪽 아래 모니터에서 다섯 캐릭터가 튀어나오며, 마지막에 중앙 일본어 타이틀이 등장한다. 사용자 답변에 따라 포스터의 일본어 로고를 유지한다. 모니터 점등, 캐릭터별 발사, 원형 충격파, 별과 색종이, 탄성 로고 등장으로 약 6초 분량의 시퀀스를 만든다.

크림색 배경, 초록색, 노란색, 굵은 윤곽선, 종이 질감과 점무늬를 사용한다. 데스크톱은 펼쳐진 포스터, 모바일은 세로 포스터 레이아웃. 작은 내비게이션과 재생 컨트롤, 캐릭터 소개를 포함한다. 실제 행사 예매나 날짜는 재현하지 않는다.

## 기술 및 파일 경계

설치 의존성 없는 HTML/CSS/ES modules. 브라우저 Web Animations API로 캐릭터와 로고를 제어하고 Canvas 2D로 파티클을 렌더링한다. `scene.js`는 타이밍과 좌표 계산, `animation.js`는 재생과 일시정지, `particles.js`는 파티클, `audio.js`는 선택형 효과음, `main.js`는 UI를 담당한다.

투명 PNG 캐릭터 5종과 일본어 로고는 내장 이미지 생성 도구로 포스터를 참조하여 제작한다. 결과는 `assets/` 안에 저장한다. 모니터, 장식, 단순 아이콘은 CSS/SVG 그래픽이다.

## 동작과 접근성

이미지 로드 후 최초 자동 재생. 재생, 일시정지, 건너뛰기, 음소거 해제, 캐릭터 소개 다이얼로그. 효과음은 명시적으로 켠 뒤에만 재생. reduced-motion 사용자는 정지된 완성 화면부터 시작한다. 키보드 조작, 포커스 표시, 대체 텍스트, 모달 Escape 닫기. 연속 재생 시 기존 타이머와 애니메이션을 취소하고 창 크기 변경 시 시작점 좌표를 다시 계산한다.

## 검증 및 Git

타이틀이 캐릭터 등장보다 늦는지와 좌표 계산을 Node 테스트로 검증한다. 브라우저에서 데스크톱/모바일 화면, 재생/일시정지/건너뛰기, 캐릭터 다이얼로그, 음향, 콘솔 오류, reduced-motion을 확인한다. 지정 GitHub 원격 저장소를 origin으로 연결하고 codex/keroro-invasion 브랜치에서 한국어 커밋으로 관리한다. 외부 라이브러리나 계정 서비스 없이 로컬과 정적 호스팅에서 동작한다.
