# 검증 기록

2026-10-14. Node.js 22 / 로컬 Chrome, 실제 브라우저 검증.

- Node 테스트: 5명 모두 등장 완료 후 타이틀 표시, 데스크톱/모바일 시작점 좌표, 동일 시작점의 0 오프셋.
- 데스크톱 1440px: 에셋 5종 로드, 타이틀 등장, 진행률, 재시작, 일시정지/계속, 건너뛰기.
- 일시정지 중 시간축과 캐릭터 transform이 변하지 않음.
- 완료 화면에서 움직임을 멈춰도 캐릭터 소개와 CTA 사용 가능.
- 캐릭터 프로필 5종, Escape 닫기, 프로젝트 소개, 효과음 켜기/끄기.
- 빠른 연속 재생 5회 후 정상 완료.
- 375 / 390 / 768px: 가로 넘침 없음, 캐릭터 소개 다이얼로그 정상.
- reduced-motion: 완성 화면 즉시 표시. 설정을 해제하면 일시정지 제어 활성화.
- 에셋 로드 실패 시 로딩 화면을 종료하고 안내 표시.
- 브라우저 런타임 오류 없음.

독립 코드 리뷰에서 발견한 초기 로딩 시 투명 버튼 노출, 완료 상태 일시정지 시 상호작용 차단, 동작 줄이기 해제 후 버튼 상태 불일치를 수정했다. 추가로 완료 장면 일시정지 후 리사이즈/재개 시 부유 동작 복원을 수정했다.

사이트는 생성된 투명 복원 에셋을 사용한다. 자동 테스트는 이미지의 미술적 동일성을 판정하지 않으며, 브라우저 스크린샷과 원본 포스터는 시각적으로 확인했다.
